# NEXUS — Agência Digital

## Sobre o projeto

A NEXUS é um projeto de desenvolvimento web que
representa uma agência digital fictícia, com foco
em inovação, criatividade e tecnologia.

O projeto foi desenvolvido utilizando HTML5 e CSS3.

## Objetivos

- Desenvolver páginas web.
- Aplicar conceitos de HTML e CSS.
- Trabalhar com versionamento utilizando Git.
- Utilizar o GitHub para colaboração.
- Criar um site responsivo.

## Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo index.html em um navegador.
